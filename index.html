What changed vs. today

  1. Approve / Hold / Rollback all take an amount. A request is no longer approved, held or reversed as one block — each action works on a slice of it.
  2. The amount is prefilled with the open amount; type any smaller number to act on a slice.
  3. Approve: only the free-text seller message appears, and only when you release less than the open amount. No internal reason or note is captured.
  4. Hold: freezes that amount with a status and reason; the rest of the request stays actionable.
  5. Rollback: returns that amount to the seller balance and recalculates cashflow; the rest stays in the request.
  6. List gains RELEASED / HELD / REMAINING: remaining = requested − released − held − returned.
  7. A released slice creates a child payout with parentId; seller sees the split in Balance + payout detail, plus push and email.
